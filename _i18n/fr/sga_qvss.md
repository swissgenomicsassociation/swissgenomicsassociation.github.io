## Qualifying Variant Set Standard (QVSS)

Dernière mise à jour : 20260605

- [Dernière version PDF du standard]({{ '/assets/release/sga_qvss/latest/sga_qvss_1.0.pdf' }}){: target="_blank"}
- [Dernière version HTML du standard]({{ '/assets/release/sga_qvss/latest/sga_qvss_1.0' }}){: target="_blank"}

Le Qualifying Variant Set Standard (QVSS) définit une représentation minimale et interopérable de critères fondés sur des règles, utilisés pour déterminer si des enregistrements de variation génétique se qualifient dans un contexte d’analyse génomique déclaré.

QVSS vise à rendre les critères de qualification des variants portables, auditables, reproductibles et réutilisables dans les études génomiques, les pipelines, les registres et les environnements d’implémentation.
