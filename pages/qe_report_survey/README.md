# Survey
We are running an anonymous A/B survey with the Swiss Genomics Association to compare two versions of a patient-facing genetic report. Both versions use the same questions; only the report differs. Target sample size is ~64 participants per group (≈130 total) to detect a 0.5-point difference on a 5-point Likert scale.
